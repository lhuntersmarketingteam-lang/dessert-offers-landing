# Лендинг пропозицій Dessert

Жива вітрина актуальних оферів. Веде трафік з реклами на картки товарів на desssert.com.ua.
Своєї корзини немає — усі покупки відбуваються на основному сайті.

Дві версії сторінки в одному файлі:

- **«Той самий»** — тепла, для дорослої аудиторії. `?svit=tepliy`
- **«Бо хочу»** — яскрава, для молоді й мам. `?svit=bo-hochu`

Реклама веде одразу на потрібну: саме ці адреси ставте в оголошення.

---

## Як оновити офер тижня

Весь змінний вміст лежить в одному файлі — **`index.html`**, у блоці `OFFERS` ближче до кінця.
Шукайте рядок `ВМІСТ ЛЕНДИНГА` — нижче починається те, що можна редагувати.

Правити можна просто в браузері на GitHub: відкрийте `index.html` → олівець «Edit» →
змініть → **Commit changes**. Через хвилину сайт оновиться сам.

### Поміняти ціну

Знайдіть товар і виправте `price`:

```js
{ name: 'Торт «Тріумф»', price: '853,75 ₴', unit: '', ... }
```

- `price` — ціна рядком, кома як роздільник, пробіл перед `₴`.
- `unit` — за скільки. Наприклад `'/300 г'`, `'/1 кг'`. Якщо ціна за штуку чи набір — лишайте порожнім `''`.

**Не пишіть ціну за 100 г.** Мінімум — 300 г, краще цілий набір.

### Замінити товар

```js
{
  name: 'Набір «Харківська Мрія»',      // назва на картці
  caption: 'Харків у коробці',           // великий напис на фото, можна прибрати
  badge: 'Пропозиція тижня',             // плашка в кутку, тільки в першого товару
  price: '493,75 ₴',
  unit: '',
  img: 'img/kharkiv.webp',               // файл із папки img
  slug: 'kharkivska-mriya',              // латиницею, для аналітики
  url: '/ua/nabory/.../nabor-kharkovskaya-mechta'   // адреса картки на сайті
}
```

**`url`** — це хвіст адреси товару на desssert.com.ua, усе після домену.
Відкрийте картку товару на сайті, скопіюйте адресу, приберіть `https://desssert.com.ua`.

**`slug`** — довільна мітка латиницею без пробілів. За нею в аналітиці буде видно,
який саме товар клікали.

### Додати фото

Покладіть файл у папку `img` і впишіть його назву в `img:`.
Формат — `.webp`, квадрат, бажано 760×760, вага до 200 КБ.
Фон на фото має бути білий: сторінка сама підставить колір картки.

### Поміняти заголовок сторінки

У блоці `hero` кожного світу:

```js
hero: {
  kicker: 'Той самий',                        // маленький напис зверху
  title: 'Смак, родом із дитинства',          // великий заголовок
  text: 'Торти, печиво й цукерки, ...',       // абзац під ним
  cta: 'Обрати смак',                         // напис на кнопці
  mosaic: ['img/triumf.webp', ...],           // чотири фото праворуч
  stamp: '17 років · з Харкова'               // кругла печатка на фото
}
```

### Поміняти передбачення

Список `FORTUNES` — просто рядки в лапках через кому. Додавайте й прибирайте скільки треба.

## Чого робити не варто

- **Не чіпайте все, що вище блоку `ВМІСТ ЛЕНДИНГА`** — там верстка й логіка сторінки.
- **Не прибирайте коми** між товарами й **лапки** навколо тексту — сторінка перестане працювати.
- Якщо в тексті потрібен апостроф, пишіть `’` (а не `'`), інакше рядок обірветься.
- Після збереження відкрийте сайт і перевірте: якщо щось зламалося, на GitHub можна
  повернути попередню версію через вкладку **History**.

## Аналітика

Події вже надсилаються, лишилося вставити ID. У файлі знайдіть `function track`.
Над ним треба додати код GA4, Meta Pixel і TikTok Pixel — **ті самі ID, що на основному сайті**,
інакше покупки не звʼяжуться з лендингом.

Що відстежується:

| Подія | Коли |
|---|---|
| `world_switch` | перемкнули світ |
| `hero_cta` | натиснули кнопку в першому екрані |
| `product_click` | клікнули товар |
| `catalog_click` | пішли в каталог |
| `social_click` | пішли в Instagram або TikTok |
| `prediction_open` | розламали шоколадку |

Усі посилання на сайт мають UTM-мітки: `utm_source=landing`, `utm_medium=offer`,
`utm_campaign` — назва світу, `utm_content` — slug товару.

## Що ще не зроблено

- **Два товари без карток на сайті.** «Алкогольні цукерки «Польща»» і «Набір новинок «Бо хочу»»
  поки ведуть на категорію. У коді над ними стоїть помітка — замініть `url`, коли картки зʼявляться.
- **ID аналітики** не вставлені.
- **Власний домен.** Зараз адреса від Vercel. Для реклами потрібен піддомен
  `offers.desssert.com.ua`, щоб лендинг і сайт були під одним пікселем.

---

## Технічне

Звичайна статична сторінка: один `index.html`, папки `img` і `fonts`.
Ніякого складання не треба — Vercel просто роздає файли.

Шрифти: Dela Gothic One (заголовки) і Jost (текст, тимчасова заміна TeX Gyre Adventor).
